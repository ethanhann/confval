# Sample configurations

The dotted `valid.confval.<format>` files are the canonical samples.
Each format directory also has a twin of that file under a single made-up extension.
The five extensions are `.confvalh`, `.confvalj`, `.confvalk`, `.confvalt`, and `.confvaly`.
The twin lets an IDE register one language server per format on a unique file pattern.
The twins are for local development only.
