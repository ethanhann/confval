The two constraint macros take attributes and a visibility.
The six constraint modules move out of `pipeline` into `constraints`.

{/* truncate */}

## Highlights

- A constraint declared with `range_constraint!` or `length_constraint!` takes a visibility and a `#[doc]`.
  A project can then hold every bound in one module.
- The constraint checkers moved from `confval::pipeline` to `confval::constraints`.
  The prelude and the crate root are unchanged.

## Added

- `range_constraint!` and `length_constraint!` take attributes and a visibility before the constant name, the way `keyword_enum!` does.
  Write them inside the call, as in `range_constraint!(/// The port.\n pub PORT, i64, min: 1, max: 65535)`.
  A constraint declared with `pub` in one module is usable from another.
  A `#[doc]` on it satisfies a crate that denies `missing_docs`.
  Every current call compiles unchanged.

## Changed

- The six constraint modules moved from `confval::pipeline` to a new `confval::constraints` module: `format`, `keyword`, `length`, `non_empty`, `range`, and `unique`.
  `confval::pipeline` keeps the `Lower`, `Validate`, `narrow`, and `check_references` stages.
  The crate root re-exports and the prelude are unchanged.
  A spec that uses `confval::prelude::*` or `confval::RangeConstraint` needs no change.

## Deprecated

## Removed

- The `confval::pipeline::format`, `confval::pipeline::keyword`, `confval::pipeline::length`, `confval::pipeline::non_empty`, `confval::pipeline::range`, and `confval::pipeline::unique` module paths.
- The `confval::pipeline::check_format`, `check_each_format`, `format_constraint`, `NON_EMPTY`, `NonEmptyConstraint`, `UNIQUE`, and `UniqueConstraint` re-exports.
  Each one is at the same name under `confval::constraints`.
- The `length_constraint!(NAME, min: 1, max: 2, help: None)` spelling.
  It was a forwarding form inside the macro and was never documented.
  Omit `help:` for a bound with no help line.

## Upgrading

If your crate names a constraint through `confval::pipeline::`, change the path to `confval::constraints::`.
A crate that uses the prelude or the crate root needs no change.

```toml
[dependencies]
confval = { version = "0.11", features = ["derive", "hcl", "color"] }
```
