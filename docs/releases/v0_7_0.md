## Highlights

- New KDL frontend
- Three configuration representations from one loaded spec: a source view, a populated view, and a runtime view

## Added

- Top-level struct specs now have their comments harvested for templates.
- `ToFields::to_source_fields`, the source view: the fields the operator set, with defaults omitted, keyed on the attached span. It renders through the existing emitters in any format.
- `keyword_enum!` now generates a `serde::Serialize` impl behind the `serde` feature, writing the keyword string so a serialized config spells `"log"` rather than the Rust variant name.
- `Value::spanned`, the span-carrying value constructor, and `Field::at`, which locates a constructed field.
- `FieldsBuilder`, `Walk`, and the sealed `Leaf` trait, for a handwritten `ToFields`. The builder takes the walk as a parameter, so an impl lists its fields once and both `to_fields` and `to_source_fields` read that one list. The recursion into nested blocks follows the walk as well. `Leaf` names the scalar types a field can hold, and no crate outside confval implements it, so the list can grow in a minor release.
- `parse_path_field`, which reads a `Located<PathBuf>` field. The derive now generates this call for that shape.
- `KeywordSet::check_each`, and `narrow::keyword_list` and `narrow::opt_keyword_list`, for keyword list fields on the validation side and the lowering side.

## Changed

- Reworked HCL templates to be emitted with a canonical block layout and ordering.

## Upgrading

The one breaking change is on the write path.
`ToFields` gains a required method, `to_source_fields`.
Every spec built with `#[derive(Spec)]` gets it generated, so no change is needed there.
A handwritten `ToFields` impl must add the method, returning the fields the source set.
Build both walks with `FieldsBuilder`, which takes the walk as a parameter and applies that rule per field, rather than writing the span checks by hand.

Enabling the `serde` feature now adds a `Serialize` impl to every `keyword_enum!` type.
A crate that already wrote its own `Serialize` for such an enum removes it.
