The `confval` and `confval-derive` crates now share a single version and are released together.
From this release on, one version number and one set of release notes cover the whole workspace.

{/* truncate */}

## Highlights

- Unified workspace versioning.
  `confval` and `confval-derive` are now versioned in lockstep through `[workspace.package]`.
  `confval` pins its derive crate with `confval-derive = "=0.4.0"`, so a given `confval` always resolves the matching derive.

## Changed

- `confval-derive` moves from `0.1.1` to `0.4.0` to align with `confval`.
  This is a version-number change only.
  There is no change to the derive macro output or its public API.

## Upgrading

Depend on `confval` as before.
The `derive` feature continues to pull in the matching `confval-derive` automatically.

```toml
[dependencies]
confval = { version = "0.4", features = ["derive", "hcl", "color"] }
```
