LSP support for cross-file validation rules. 

{/* truncate */}

## Highlights

- Workspace-level validation for LSP server.

## Added

- Workspace-level validation in `confval-lsp`.
  The `WorkspaceValidator` trait, the `DocumentIndex` and `IndexedDocument` read view of the open documents with their lowered specs, the `WorkspaceReport` keyed by document URI, and `serve_multi_with` or `Router::with_workspace_validator` to register one.

## Upgrading

`confval_lsp::handlers::diagnostics` now returns the spec its validate pass built beside the diagnostics, as a `(Vec<Diagnostic>, Option<Box<dyn Any>>)` pair due to the new workspace validation feature. Destructure the pair where it was called before.
